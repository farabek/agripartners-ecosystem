# Security Policy

## Reporting a vulnerability

Please do not disclose an unpatched vulnerability in a public issue. Use the
private vulnerability reporting feature in the affected GitHub repository. If
the affected repository is unclear, report it through the Security tab of
[`farabek/agripartners`](https://github.com/farabek/agripartners/security).

Include the affected component, reproduction steps, impact, and any suggested
mitigation. Do not include real credentials, personal data, or production
secrets in a report.

## Scope

Executable product security is owned by `farabek/agripartners`. This repository
contains governance documents only and accepts reports about cross-repository
information exposure, unsafe ownership boundaries, or sensitive-data leakage.
